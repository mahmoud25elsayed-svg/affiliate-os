# البرومبتات: من الصفر إلى المشروع الكامل

هذه هي **خطة التنفيذ الرسمية** على شكل برومبتات لـ Claude Code. تحل محل الترتيب الأسبوعي في [07](../docs/07-implementation-plan.md)، وتبقى جداول المهام في 07 ومخطط 03 والمعمارية في 02 مرجعًا تفصيليًا.

## طريقة الاستخدام

1. افتح Claude Code داخل مجلد المستودع.
2. نفّذ البرومبتات **بالترتيب**. برومبت واحد لكل جلسة (أو `/clear` بين البرومبتات).
3. انسخ نص البرومبت كما هو من داخل الكتلة.
4. لا تنتقل للتالي قبل أن تتحقق **معايير القبول** ويكون CI أخضر ويُدمج الـ PR.
5. إن فشل شيء: اطلب من Claude إصلاحه داخل نفس البرومبت، ولا تتخطاه.

القواعد الثابتة (الحدود، المال، الحالات، الـ Clean-room) يكتبها `P02` في `CLAUDE.md`، فيقرأها Claude تلقائيًا في كل جلسة.

## صيغة كل برومبت

كل برومبت يحتوي: **الهدف، اقرأ أولًا، المطلوب، القيود، معايير القبول، الخاتمة** (فرع + اختبارات + PR). إذا تعارض برومبت مع `CLAUDE.md`، فـ `CLAUDE.md` يغلب، ويجب على Claude التنبيه.
