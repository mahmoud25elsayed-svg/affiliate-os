# 11 — دراسة بوابات الدفع الإلكتروني للاشتراكات المتكررة في مصر (SaaS Recurring Billing)

## 1. المقدمة والتحدي المحلي في مصر
تشغيل نموذج البرمجيات كخدمة (SaaS) في السوق المصري يواجه تحديات تقنية وتشريعية خاصة بالدفع المتكرر (Recurring Billing / Card-on-File):
- **قواعد البنك المركزي المصري (CBE) وتأكيد الدفع (3D-Secure 2.0):** معظم البطاقات المحلية المصرفية تتطلب رمز تحقق لمرة واحدة (OTP) عبر الرسائل النصية عند كل حركة شراء عبر الإنترنت، مما يجعل السحب الآلي التلقائي الصامت بدون تدخل العميل (Off-Session Merchant-Initiated Transactions) مقيدًا بشروط صارمة وعقود تجارية مباشرة مع البنوك المكتسبة (Acquiring Banks).
- **انتشار وسائل الدفع البديلة غير القائمة على السحب التلقائي:** إنستاباي (Instapay)، المحافظ الإلكترونية (Vodafone Cash, Orange, Etisalat, WE)، وفوري (Fawry Pay). هذه الوسائل تعتمد على نموذج الدفع بالطلب (Push Payment) بدلاً من السحب الدوري الآلي (Pull Payment).

| **PayTabs Egypt** | نعم (Recurring Billing) | نعم (Agreement API / Token Recurring) | نعم (Visa/Mastercard) | كروت بنكية، محفظة إلكترونية، ميزة | - يوفر `Recurring Payments API` عبر الربط مع بنك مصر.<br>- يتطلب فتح حساب تاجر مؤسسي وسجل تجاري وبطاقة ضريبية. |
| **Kashier** | نعم (Customer Cards) | نعم (Subscriptions Module) | نعم | Visa, Mastercard, Meeza, Mobile Wallets | - يدعم حفظ البطاقات والاشتراكات الشهرية.<br>- إجراءات التسجيل والتوثيق للمشاريع المصرية سريعة وميسرة. |

## 3. التوصية الهندسية لمنظومة AffiliateOS

بناءً على طبيعة التجار والمستخدمين في السوق المصري، نوصي باستراتيجية **الهجين المتوازن (Hybrid Billing Strategy)**:

1. **المرحلة التأسيسية والحالية (Phase 0):**
   - **ManualGateway:** الدفع اليدوي والتحويل البنكي وتطبيقات الدفع الفوري (Instapay / Vodafone Cash / فوري)، حيث يرفع التاجر إيصال التحويل ويقوم مدير المنصة بمراجعته وتأكيده عبر زر واحد في `/platform`.
   - هذا يضمن تشغيل النظام فورًا بدون عوائق فتح السجلات التجارية أو الموافقات البنكية الطويلة.

2. **المرحلة اللاحقة (Phase 1/2 Integration):**
   - اعتماد **Paymob** أو **Tap Payments** كبوابة الدفع الإلكتروني الأساسية:
     - إنشاء جدول `payment_tokens` لحفظ `token_id` و `masked_pan` و `expiry`.
     - عند انتهاء الفترة التجريبية أو موعد التجديد، تشغيل Job ليلي يحاول سحب قيمة الاشتراك عبر التوكن.
     - في حال فشل السحب أو رفض البنك لحركة الـ Card-on-File، يتم إرسال إشعار فوري للتاجر مع رابط دفع مباشر سريع (Hosted Payment Link) مدفوع عبر إنستاباي أو المحفظة الإلكترونية مع منح مهلة سماح 3 أيام (`grace_period_ends_at`).

3. **الحماية وحفظ البيانات:**
   - في حال عدم الدفع بعد انتهاء مهلة السماح، يتم نقل المتجر لحالة `suspended` مع إظهار صفحة "المتجر مغلق مؤقتًا"، دون حذف أي من منتجات التاجر أو سجلاته أو عملياته.
